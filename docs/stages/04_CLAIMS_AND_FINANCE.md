# Stage 04 — grounded claims and financial reasoning

Current finance module is user-attested and experimental. Do not upgrade its labels to “verified” by renaming fields.

Build observations from reviewed cell/header/footnote bindings with metric definitions, Decimal values, currency/scale, fiscal boundaries, entity scope and restatement provenance. Quote/value membership alone cannot validate a fact. Separate source-stated, calculated and inferred claims. Typed generation must reference existing evidence IDs; exact quote, scope, period and numeric checks precede presentation. Entailment judges assist but are not proof.

Add contradiction checks only for comparable facts. Preserve management qualifiers. Calculations retain input IDs, formula/version and rounding; preserve zeros/losses and refuse invalid baselines. Test mixed units, total income vs operating revenue, standalone/consolidated, overlapping periods and restatements.

Before enabling providers, configure keys outside source control, approved runtime spend limits, request deadlines and real model/usage telemetry. Missing credentials give evidence-only mode. No silent provider substitution. Acceptance requires curated numeric cases to be correct or explicitly abstained, citation integrity and useful-answer coverage reported separately.
